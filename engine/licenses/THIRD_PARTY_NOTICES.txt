GoonerApp - third-party software
================================

GoonerApp is free software under the GNU General Public License version 3 (GPL-3.0.txt).
The packaged program also contains software written by others. Each piece is listed below with
the license it comes under; the full license texts are in this folder, and in the app Help >
Third-Party Licenses shows every one of them. Godot's own license, and those of the libraries
built into Godot, are shown there as well, read from the engine itself.

Source code. FFmpeg is passed on under the GNU LGPL. It is bundled exactly as it was built for
the video extension named below, unmodified, as dynamically linked libraries that can be
replaced. That build linked further libraries into the FFmpeg libraries; each is listed below.
Two of them, libiconv and soxr, are under the GNU LGPL as well, and GoonerApp passes them on
under its version 3, as both allow. Attached to every release of GoonerApp, in the same place as
the program itself, are the complete source code of FFmpeg, libiconv and soxr at the revisions
given below, the source of the video extension, and the scripts the FFmpeg libraries were built
with (FFmpeg-Builds), which name every library and revision that went into them. We will provide
all of it on request as well: open an issue in this project's repository. That offer stands for
three years from the date of each release. GoonerApp's own source code is in the same repository.

One part of that build cannot be pinned exactly: libiconv's build script fetches the Gnulib
helper library as it was on the day of the build (2023-07-24) rather than at a fixed revision.
Gnulib is free software under the GNU LGPL/GPL; its state of that day is commit b70b4f0 of
https://git.savannah.gnu.org/git/gnulib.git.
